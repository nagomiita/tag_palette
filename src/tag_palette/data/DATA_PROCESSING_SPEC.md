# danbooru_tags.csv データ加工仕様（1回実行版）

更新日: 2026-03-03

## 1. 目的
`danbooru_tags.csv` を **1回の実行**で分離し、
`alias` 先頭語の言語・文字種ベースで用途別CSVを同時生成する。

## 2. 実行インターフェース

### 実行コマンド（仕様）
```bash
uv run python scripts/split_danbooru_onepass.py src/tag_palette/data/danbooru_tags.csv
```

- 入力: `src/tag_palette/data/danbooru_tags.csv`
- 出力先: 入力と同じディレクトリ
- 追加ライブラリ: 不要（標準ライブラリのみ）

## 3. 判定対象
- 対象列: `alias`
- 「先頭語」定義: `alias.split(",", 1)[0].strip()`
- 先頭語に対して言語/文字種判定を行う

## 4. 処理フロー（1回実行）

### Step 1: alias有無で分割
- `alias` が空（空文字/空白のみ）を `danbooru_tags_no_alias.csv` へ出力
- `alias` がある行は以降の正規化・判定対象

### Step 2: `(` を含む語の先頭化（強制）
- `alias` 内に `(` を含む語が1つでもある場合、最初に見つかったその語を先頭に移動
- 例: `姬子,姫子,姫子(スターレイル),히메코` -> `姫子(スターレイル),姬子,姫子,히메코`
- 例外: 語が `(` で始まる場合（例: `(∪)`）は顔文字候補として先頭化対象から除外
- `(` を含む候補が複数ある場合は、日本語（ひらがな/カタカナを含む）候補を優先して先頭化

### Step 3: 日本語aliasの先頭化
- `alias` 全体に日本語（ひらがな/カタカナを含む語）が存在する場合、その語を先頭に移動
- この処理は英語/韓国語/中国語の分離より前に行う

### Step 4: 先頭語の後ろ送り正規化
先頭語が以下のいずれかに該当する場合、先頭語を末尾へ回す。

1. 小文字アルファベットのみ（`^[a-z]+$`）  
2. 韓国語（Hangul）を含む  
3. 絵文字のみ  

- 先頭語が上記に該当しなくなるまで繰り返す（最大で alias 語数回）
- 全て大文字アルファベットのみ（`^[A-Z]+$`）は後ろ送り対象にしない（そのまま維持）

### Step 5: 最終分離
Step 4 後の先頭語に基づいて、以下を分離出力する。

1. 先頭語が小文字アルファベットのみ -> `danbooru_tags_first_alias_lowercase_alpha.csv`
2. 先頭語が韓国語 -> `danbooru_tags_first_alias_korean.csv`
3. 先頭語が中国語判定に一致する -> `danbooru_tags_first_alias_chinese.csv`
4. 上記以外 -> `danbooru_tags_first_alias_japanese.csv`

## 5. 出力ファイル

### 5.1 基本分離
- `danbooru_tags_no_alias.csv`
  - 条件: `alias` なし
- `danbooru_tags_first_alias_korean.csv`
  - 条件: Step 4後の先頭語が韓国語
- `danbooru_tags_first_alias_lowercase_alpha.csv`
  - 条件: Step 4後の先頭語が小文字アルファベットのみ（`^[a-z]+$`）
- `danbooru_tags_first_alias_chinese.csv`
  - 条件: Step 4後の先頭語が中国語判定に一致
- `danbooru_tags_first_alias_japanese.csv`
  - 条件: 上記いずれにも該当しない（`alias` あり）

## 6. 判定仕様の詳細

### 6.1 中国語判定
- 先頭語に「簡体字判定用インジケータ文字」が1文字でも含まれれば該当
- さらに補助判定として、`SJIS` 往復で文字欠損が出る場合（`is_zh`）を中国語候補として扱う
- ただし、先頭語にひらがな/カタカナを含む場合は簡体字判定を行わない
- 先頭語にラテン文字（拡張ラテン含む）を含む場合は中国語判定を行わない
- 先頭語に韓国語（Hangul）を含む場合、または絵文字のみの場合は中国語判定を行わない
- 設計方針: 高精度優先（誤検出抑制）
- 注意: 取りこぼしは発生しうる

### 6.2 韓国語判定
- 先頭語にHangul Unicodeブロック文字が1文字でも含まれれば該当

### 6.3 英字判定
- 小文字のみ: `^[a-z]+$`
- 大文字のみ: `^[A-Z]+$`（後ろ送りしない）

### 6.4 絵文字判定
- 先頭語が絵文字のみで構成される場合に該当
- 該当時は先頭語を末尾へ回す

## 7. 出力形式
- 全出力CSVは入力と同一ヘッダを保持する（`tag,category,count,alias`）
- UTF-8 / 改行はCSV標準準拠

## 8. ログ出力（標準出力）
実行時に最低限以下を表示する。
- 入力ファイルパス
- 各出力ファイルパス
- 各分類件数
- 合計件数（入力件数との一致確認）

## 9. 既知の制約
- 中国語漢字と日本語漢字は共通字が多く、完全自動判定は不可
- 本仕様は先頭語のみを判定対象とする
- 文脈や語彙辞書は使わない（文字種ヒューリスティック中心）
- Step 3 の後ろ送り後も先頭語が韓国語/小文字英字のままになるケースがある
  （例: 全 alias が同種別、または候補が尽きる場合）
- 同様に、Step 4 後も先頭語が中国語判定に一致する行は `first_alias_chinese` に分離される

## 10. 互換方針
- 既存の段階実行スクリプトは保守用途として残す
- 今後の通常運用は `split_danbooru_onepass.py` を正規手順とする
- 前処理単体が必要な場合は `scripts/promote_parenthesized_alias.py` を利用する
